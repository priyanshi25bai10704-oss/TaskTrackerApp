# Personal Task & Habit Tracker

A modular Java Swing desktop application designed to track personal tasks, academic assignments, and daily habits.

## Features
- Log tasks with customizable priority levels.
- Toggle task status dynamically between **Pending** and **Completed**.
- Real-time display of completed vs. total task counts.
- Local data persistence via `tasks.txt`.

## Technologies Used
- **Language:** Java (JDK 17+)
- **GUI Framework:** Java Swing / AWT
